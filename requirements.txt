# embryo_crop needs exactly two third-party packages.
#
#   numpy      arrays, the crop, the rescale, the detector
#   tifffile   read and write TIFF
#
# The GUI additionally needs tkinter, which ships with most Python builds but is
# packaged separately by some distributions. It is not a pip package -- see
# README.md for the per-platform install. The command-line path does not need it.
#
# Optional: install `imagecodecs` only if your microscope writes COMPRESSED
# TIFFs. ACQUIFER frames are uncompressed, so it is not needed by default.

# numpy 2.x is REQUIRED: recent tifffile calls ndarray.reshape(copy=...), which
# only exists in numpy >= 2.0, but tifffile does not declare that in its own
# metadata. With `numpy>=1.24` pip will happily install numpy 1.26 alongside a
# 2026 tifffile and the pair crashes at the first imread():
#     TypeError: 'copy' is an invalid keyword argument for this function
# Found on an HPC module stack that ships numpy 1.26.
numpy>=2.0
tifffile>=2024.1.1
